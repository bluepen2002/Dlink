# Dlink — GitHub Cloud Build

Dlink is an Android-first digital contact exchange application. This repository is configured so GitHub Actions can build the Android packages without Android Studio on the user's phone.

## Cloud build

Every push to `main`/`master`, pull request, or manual workflow run triggers `.github/workflows/android-build.yml`.

The workflow:

1. Checks out the repository.
2. Installs JDK 17.
3. Provisions Gradle 8.9.
4. Builds the debug APK.
5. Builds an unsigned release APK.
6. Builds an unsigned release AAB.
7. Uploads all packages as GitHub Actions artifacts.

## Downloading the APK from a phone

On GitHub:

`Repository → Actions → Dlink Android Build → select successful run → Artifacts`

Download `dlink-debug-apk`, extract it if GitHub downloaded a ZIP, and install the APK on the Android phone.

## Important

The debug APK is for testing. The release APK/AAB generated by this workflow are unsigned and are not yet suitable for Google Play publication.

Before release we need to add a protected Android signing key through GitHub Secrets, configure release signing, versioning, Play App Signing, and production backend configuration.

## Current offline exchange transports

- Google Nearby Connections — transport foundation
- NFC Host Card Emulation / ISO-DEP — fallback
- QR + CameraX + bundled ML Kit — fallback
- Temporary encrypted QR/NFC envelope
- AES-GCM authenticated encryption for the secure fallback layer

The application still needs the final production Nearby authenticated handshake, complete field-level sharing UI, production account/subscription backend, release signing, and end-to-end device testing before being marketed as production-ready.
